## 📋 Descripción del Proyecto
EcoAcciónRD es una aplicación web interactiva desarrollada en React que permite a los usuarios registrar sus acciones ecológicas diarias. La app acumula los datos y muestra un panel de impacto visual (árboles plantados, kilos reciclados, energía ahorrada) para fomentar la conciencia ecológica y la acción social en la República Dominicana.

## 🛠️ Tecnologías Usadas
- **React.js** (Hooks: useState, useEffect)
- **JavaScript** (ES6+)
- **HTML5 y CSS3** (Diseño responsive, animaciones, modo oscuro)
- **LocalStorage** (Para guardar los datos y que no se borren al recargar)
- **Git & GitHub**

## 🧠 ¿Qué aprendimos?
- A manejar el estado global en React y pasar props entre componentes.
- A utilizar `useEffect` para interactuar con el almacenamiento local del navegador.
- A implementar variables CSS para crear un sistema de diseño (Modo Claro / Oscuro).
- A dividir el trabajo en equipo usando ramas y pull requests.
